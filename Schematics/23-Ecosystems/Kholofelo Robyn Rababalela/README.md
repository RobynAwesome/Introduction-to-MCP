## Minimal RUNE boundary

The active public implementation should preserve the minimal loop:

`claim → evidence → state → action → receipt`

Do not inflate RUNE into a finished standard or proven production authority before receipts justify that promotion.

## Publication law

A public claim must remain in one of these states until evidence changes it:

- `VERIFIED`
- `PARTIAL`
- `OBSERVED`
- `SELF_ASSERTED`
- `PENDING_EVIDENCE`
- `STALE`
- `CONTRADICTED`
- `QUARANTINED`

Private evidence is not automatically a public asset.
