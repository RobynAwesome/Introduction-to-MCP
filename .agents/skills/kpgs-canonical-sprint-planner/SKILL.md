```text

  ├── Enforce Zero-Trust boundary (State honesty + scope lock)
  └── Composite score ≥ 80%?  --> ADMIT SPRINT (Else: REVISE)
         |
         v
[ PHASE 2: METAL EXECUTION ]
  ├── Implement on local developer metal
  ├── Run fast deterministic validation (<30s feedback loop)
  └── No unvetted dependencies or platform sprawl
         |
         v
[ PHASE 3: VERIFICATION & SEAL ]
  ├── Run automated test suites (unit, typecheck, health-check)
  ├── Produce unalterable completion receipt
  └── Update volatile authority (NOW.md)
```
