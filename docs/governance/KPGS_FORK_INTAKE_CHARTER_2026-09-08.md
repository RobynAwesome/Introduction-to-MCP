## 0. Foundational Correction

> **Forked ≠ admitted. Useful ≠ trusted. Pattern source ≠ dependency.**

Upstream forks are **capability archaeology**, not runtime landlords.

| Forbidden default | Required default |
|---|---|
| Discover → Fork → `npm install` | Discover → Fork → Quarantine → Archaeology → Extract Pattern → Threat Audit → KPGS Translation → POC → Receipt → Graduate |
| Provider defines the OS | Provider supplies seats / patterns; **KPGS defines the constitution** |
| “It works” ⇒ graduate | Graduation only via one of four outcomes below |

**One-Engine Law (providers):** Cursor, Codex, Kiro, Gemini, Qwen, ADK, etc. may supply intelligence and patterns. **They do not define the operating system.** They are **seats**, not constitutions.

## 1. Graduation Outcomes (only four)

Every fork archaeology must terminate as exactly one:

| Outcome | Meaning |
|---|---|
| **`ADMITTED`** | Permitted KPGS component under native contracts |
| **`PATTERN_ONLY`** | Knowledge extracted; upstream **never** enters runtime |
| **`RESEARCH_ONLY`** | Retained for experimentation; no production authority |
| **`DECLINED`** | Incompatible, redundant, or unsafe |

Interim intake states (pre-graduation) may be: `QUARANTINE`, `PATTERN_ADMIT`, `ADMIT_TO_CURRICULUM`, `TRAINING_LAB`, `DOCS_TOOLBOX`, `OPTIONAL_UX`, `DORMANT_ORGAN`, `DOMAIN_RESEARCH`.

## 6. Sleeper hit — universal gate primitive (`cf_ai_approvalflow-ai`)

Central question for capable agents is no longer only *can this execute?* but:

> **Who is authorized to let this action cross the boundary?**

Reusable decision primitive:

```text
REQUEST
   ↓
CLASSIFY CONSEQUENCE
   ↓
┌─────────────────────┐
│ ROUTINE / REVERSIBLE│ → AUTO-LEASE → EXECUTE → RECEIPT
└─────────────────────┘

┌─────────────────────┐
│ MATERIAL / SENSITIVE│ → HUMAN GATE → APPROVE/DENY → RECEIPT
└─────────────────────┘

┌─────────────────────┐
│ UNKNOWN / CONFLICT  │ → BLOCKED → ESCALATE
└─────────────────────┘
```

Candidate scope for this primitive: GitHub merges, Vercel production, desktop actions, financial APIs, public publishing, DNS, account permissions, destructive filesystem ops — **anything with consequence**.

This is larger than “approval-flow UX.” It is a candidate **KPGS universal gate primitive**.
