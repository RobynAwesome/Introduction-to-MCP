## Public Surface Validation Rule

For a public product site, **POC is not “the page explains why the system is careful.”**
POC is the user-visible job completing against reality with a receipt.

Default validation audience order:

1. **Primary:** the human visitor/customer performing the product job.
2. **Secondary:** the business/operator responsible for the transaction or service.
3. **Tertiary:** search engines, analytics, internal governance, agent orchestration and architecture evidence.

If tertiary validation materially degrades the primary job, classify **FOC-G07** and remove it from the public surface.

Examples:
- booking site → validated when a real court/rate/slot can be transacted, or a direct venue confirmation path works;
- event page → validated when event state is backed by authoritative event records, not because an archive component exists;
- ecosystem graph → internal evidence unless the visitor explicitly needs cross-estate navigation to complete their task.
